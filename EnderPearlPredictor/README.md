# Ender Pearl Predictor - Minecraft 1.21.11 Fabric

Client-side Fabric mod that predicts an Ender Pearl path without requiring a pearl in hand.

## Controls
- P = prediction on/off
- O = open settings menu

## Browser build with GitHub Codespaces
1. Upload this folder to a GitHub repository.
2. Open `Code -> Codespaces -> Create codespace`.
3. In the terminal run `./gradlew build` once the Gradle wrapper has been generated by your GitHub template, or install Gradle and run `gradle build`.
4. The jar will be in `build/libs/`.

## Dependencies
Minecraft 1.21.11, Fabric Loader 0.19.4+, Fabric API 0.140.0+1.21.11.
